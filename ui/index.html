      Running in the background

      Check for updates

      While the app is running, even tucked in the tray, it checks all your games every so often. When new updates turn up and the window isn't in front of you, a Windows notification lists them.

      Keep running in the tray

      Closing the window tucks the app into the system tray, the small icons by the clock, instead of quitting. Click the icon to bring it back. To quit, right-click it and choose Exit.

      Start with Windows

      Opens the app when you sign in to Windows.

      Let's set up your addons

      Two things and you're done. After this, checking and updating is one click.

      1. Connect to CurseForge

        CurseForge asks every app for a free API key. Sign in at console.curseforge.com, open API keys, copy yours, and paste it here.

        Connected

      2. Pick your games

        Tick the games and WoW versions you want to manage. Each WoW version gets its own addon list. You can add more later from the game menu.
